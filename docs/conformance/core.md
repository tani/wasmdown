# Core conformance baseline

Generated by `make test-spec-core` (tools/run-spec-core.lisp). Lane index: [`docs/conformance/README.md`](README.md).

A **baseline, not a gate**: the runner reports and exits zero, so read the
counts rather than the exit code. Every executed command gets exactly one
outcome; `unsupported` is a suite feature this engine classifies as out of
scope and is never rewritten as a pass. The 73 unsupported commands of the
pinned run are the unadopted-annotations proposal (docs/design/PLAN.md §3.3).
Pinned comparison: pass 21,187 / fail 0 / unsupported 73; a moved count must
be explained in the same change that moves it.

- Engine scope declared: MVP + bulk-memory + sign-ext + non-trapping-float + multi-value + reference-types (`partial`, docs/design/PLAN.md §2)
