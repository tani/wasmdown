# Backend parity

Generated by `make report-backend-parity` (tools/run-backend-parity.lisp). Lane index: [`docs/conformance/README.md`](README.md).

The same pinned scripts run twice in one process, once with
`wasmdown.wast:*instantiate-mode*` bound to `:interpret` and once to
`:compiled` (the compiled backend lowers every defined function of
the module). A **pair** is one command executed by both backends,
matched by case id; two backends never share a wast-state, and the
backend entry counters are zeroed before each run.

A **match** is the same outcome *and* failure phase in both modes.
Anything else is a **diverge** and is classified below; a compiled
`compile` phase is a refusal to lower an instruction, never a
silent fall back to the interpreter.
